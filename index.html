Binomial Distribution Module

Explore the probability of a specific number of successes across independent Bernoulli trials.

Parameters

0.50

Mathematical Formula

P(X = k) = ⁿCₖ · pᵏ · (1-p)ⁿ⁻ᵏ

Where ⁿCₖ = n! / (k!(n-k)!) represents the binomial coefficient.

Probability Mass Function (PMF) Graph

Statistical Properties

Mean (μ) = 5.00
Variance (σ²) = 2.50
